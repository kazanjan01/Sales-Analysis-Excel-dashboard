## Project Overview

This project demonstrates an end-to-end sales data analysis workflow using Microsoft Excel. The objective was to transform raw sales data into meaningful business insights through data cleaning, transformation, analysis, and interactive dashboard development.

The project follows the complete analytics lifecycle, beginning with raw data preparation and ending with an executive dashboard designed to support business decision-making.

---

## Business Objective

The objective of this project was to:

- Clean and prepare raw sales data.
- Create a structured dataset for analysis.
- Develop calculations for business KPIs.
- Analyze sales performance using Pivot Tables.
- Build an interactive dashboard for decision-making.

## Project Workflow

The project follows this structured workflow:

1. Master Data
2. Input Data
3. Cleaned Data
4. Calculations
5. Pivot Analysis
6. Interactive Dashboard

---

## Workbook Structure

| Worksheet | Description |
|-----------|-------------|
| 01 Master Data | Original source data |
| 02 Input Data | Consolidated input dataset |
| 03 Cleaned Data | Data cleaning and preparation |
| 04 Calculations | Supporting calculations and formulas |
| 05 Pivot Analysis | Analytical summaries using Pivot Tables |
| 06 Dashboard | Interactive dashboard for business insights |

## Dashboard Features

The dashboard provides insights into:

- Total Revenue
- Gross Profit
- Profit Margin
- Sales by Category
- Sales by Sales Type
- Gross Profit by Sales Type
- Quantity Sold
- Payment Method Distribution
- Interactive Filters (Slicers)
